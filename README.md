# GitCat 🐱

A tiny, fast AI git agent for your terminal. Type what you want in plain English
("commit my changes and push", "undo the last commit but keep my work"); a small
model picks from ~95 prebuilt git/gh operations, GitCat builds the exact
commands, runs them, and fixes the common failures itself.

How to run it: **[start_commands.md](start_commands.md)** — or `gitcat` in any repo once installed.
How it works: **[docs/architecture.md](docs/architecture.md)** (browsable: [docs/architecture.html](docs/architecture.html)).
